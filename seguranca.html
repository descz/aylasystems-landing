Segurança

Tecnologia oficial. Operação responsável.

A Ayla opera pela API corporativa do WhatsApp e trata cada conversa como dado sensível.

API oficial

Operação pela API corporativa do WhatsApp. Sem automação irregular e sem risco de bloqueio por uso indevido.

Criptografia em trânsito

Todo o tráfego entre navegador, servidores e API usa TLS. Credenciais ficam fora do código e do navegador.

Dados mínimos

Coletamos apenas o necessário para triagem, agendamento e suporte. Nada de formulário com campo sobrando.

Acesso restrito

Conversas e credenciais ficam limitadas à operação. Cada acesso é feito por pessoa autorizada.

Registro auditável

Cada atendimento gera histórico para revisão, correção e comprovação do que foi combinado.

Transbordo humano

Casos fora do roteiro vão para a equipe com o contexto completo. A automação não decide sozinha.

Transparência técnica: a criptografia ponta a ponta do WhatsApp se aplica às conversas entre usuários. Na API Business, a integração usa TLS entre os sistemas envolvidos.
